계좌명은 사용자가 짓습니다
NH 의 계좌 목록 응답에는 acct_no 와 acct_type 뿐입니다 — 종합계좌·CMA·IRP 를 알려 주는 필드가 없습니다. 앱이 계좌번호로 종류를 추측하면 틀렸을 때 엉뚱한 계좌를 열게 됩니다. 이름은 사용자가 붙이고, 붙이기 전까지는 API 가 주는 계좌구분(운영 일반 / 주문대리인)을 흐린 글자로 대신 씁니다.
요약은 계좌 수만큼 호출이 늡니다
지금 이 화면은 API 를 한 번 부릅니다. 요약을 채우려면 계좌마다 잔고를 더 불러야 하므로 계좌 수만큼 늘어납니다(NH 는 초당 약 5건). 계좌가 서너 개면 문제없지만, 먼저 목록을 그리고 요약은 도착하는 대로 채웁니다 — 숫자가 없다고 화면을 붙잡지 않습니다.
